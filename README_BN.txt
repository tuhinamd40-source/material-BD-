Metro Rail BD — PWA source
এই ZIP-এ ওয়েব অ্যাপের ফাইল আছে। এটি APK নয়।
Android 11+, iPhone এবং ল্যাপটপে ব্রাউজার দিয়ে ব্যবহারযোগ্য।
ইনস্টলযোগ্য PWA ও GPS ব্যবহারের জন্য HTTPS-সহ ওয়েব হোস্টিং দরকার।
ফাইলগুলো GitHub Pages / Netlify / Cloudflare Pages-এ প্রকাশ করলে লিংক দিয়ে ব্যবহার করা যাবে।
GPS-এর কাছের স্টেশন হিসাব আনুমানিক স্টেশন কো-অর্ডিনেট ব্যবহার করে।
ভাড়া প্রকাশিত MRT Line-6 ভাড়া তালিকা থেকে অন্তর্ভুক্ত; ভ্রমণের আগে অফিসিয়াল DMTCL তথ্য যাচাই করুন।
এটি DMTCL-এর অফিসিয়াল অ্যাপ নয়।
